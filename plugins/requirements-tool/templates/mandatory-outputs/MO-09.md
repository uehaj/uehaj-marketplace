# MO-9 — コスト・予算枠の確定

## 決めるべきこと
開発時コスト（API 利用料・ツール・ライセンス）、運用時コスト（インフラ・保守工数・課金 API の継続利用）、それぞれの許容上限と超過時の扱い。

## 確定の目安
課金を伴う手段を選択する前（例: headless テストの API 課金、外部サービスの採用）。

## axes 提案根拠（AI 提案 — 要レビュー）
予算枠自体は見直せるが、超過してしまった支出は取り返せないため reversibility=medium。レコード間で参照される契約ではないため boundary=false。
