# MO-4 — 配布・デプロイ形態の確定

## 決めるべきこと
配布方法（パッケージレジストリ／git ベース／プラグイン機構等）、インストール手順、アップデートの経路と互換性方針、デプロイ先（該当する場合）。

## 確定の目安
最初の外部利用者が導入する前。導入済み利用者が増えるほど形態の変更が高くつく。

## 本プロジェクトでの注記
SR-26（他プロジェクトへのインストールとアップデート）により、配布・アップデートの形態（npm／Claude Code プラグイン／git ベース等）は未裁定の手段選択（再考があり得る決定のため ADR 対象）として裁定待ち登録済み（changelog v0.15 参照）。

## axes 提案根拠（AI 提案 — 要レビュー）
導入・更新の経路は利用者から見える契約なので boundary=true。移行パスを用意すれば変更可能なため reversibility=medium。

## 状態
未決（カタログから投入された定型要件。確定・非該当却下は施主裁定）。
