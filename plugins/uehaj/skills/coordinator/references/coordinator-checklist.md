# コーディネーターのチェックリスト

メッセージや完了通知が来るたび、また報告の前に上から見る。

- [ ] 届いたメッセージの送り手を `from` で確かめた。同名のセッションが居ないか ListAgents で見た。
- [ ] 質問は「決める」か「ユーザーに確認」かに分けた（SKILL.md の表）。決めたものは答え、状態ファイルの「決め打ち」に書いた。
- [ ] ユーザーに確認するものは、原文の引用と選択肢と推奨案を添えて「返事待ち」に書いた。待つ間、他の仕事は止めていない。
- [ ] 振る仕事には担当が 1 人だけ。ブランチ・PR と担当を状態ファイルの「担当」に書いた。
- [ ] 完了報告の PR は、実装担当と別の担当がレビューした（[review-and-merge.md](review-and-merge.md)）。
- [ ] マージ前に `gh pr view <N> --json state,headRefOid` で、レビューした head と同じか確かめた。
- [ ] 外部の人の PR、またはそのコミットを含むブランチは、ユーザーの承認なしにマージしていない。
- [ ] 実サービスを呼ぶ測定は予算の承認がある。実費を「予算」に書いた。
- [ ] 誤って伝えたことがあれば訂正を送った。
- [ ] 状態ファイルを書き直した。
- [ ] 報告は 結論 → 決め打ち → 返事待ち → 進行中 の順。

## 再開したとき（`/clear`、再起動）

- [ ] `workdir/coordinator-state.md` を読んだ。
- [ ] ListAgents と `claude agents --json` で、担当表のワーカーが居るか、`state` が `blocked` で止まっていないか見た。
      ref は変わっていることがあるので、表の宛先を一覧の値で直した。
- [ ] 担当表の PR を `gh pr view` で見て、マージ・クローズ済みのものを片付けた。
- [ ] 居なくなったワーカーの仕事は、ブランチと PR から引き継ぎ先を決めた。
